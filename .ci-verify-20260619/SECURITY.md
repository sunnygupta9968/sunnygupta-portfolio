# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues. Report them privately to `sunnygupta9968@gmail.com` with reproduction steps and the affected version or commit.

You can expect an acknowledgement within seven days. Confirmed issues will be prioritized according to impact and fixed before public disclosure where practical.

## Supported Version

Security updates apply to the latest commit on the `main` branch.
